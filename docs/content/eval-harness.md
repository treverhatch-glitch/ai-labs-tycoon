# Public eval harness

Benchmark cadence customers can see (bible ch. 8; `evalHarness.*` in the data; Q450). Five saved fields on each model (`evalSuite`, `evalLeft`, `evalScore`, `evalRuns`, `evalStreak`; schema 126). Only the player's lab.

`RegisterEval` (model, suite 1 narrow or 2 broad) costs cash and research points, sets a cadence, and starts publishing scores. Each publish compares capability and alignment to a bar and shifts trust in every sector the model sells in. A score below the bar adds tension when the lab holds board meetings (`failTension`, Q450). Low scores during a conformity review add weeks to that review (`conformityPush`).

Events: `EvalRegistered` (Pick is the suite), `EvalPublished` (Pick 1 beat, 0 miss).
